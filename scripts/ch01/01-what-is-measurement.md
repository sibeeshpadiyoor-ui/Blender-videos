# Chapter 1, Video 1: What does it mean to measure?

- **Book section:** 1-1 Measuring Things
- **Length:** about 60 seconds, vertical (Reels / Shorts)
- **One idea:** a measurement is a comparison with an agreed unit, so it always
  needs a number *and* a unit.

| Time | Narration (spoken) | On screen |
|---|---|---|
| 0–6 s | "This table is two long. Two… what?" | A table. Above it the number **2** and a large **?** |
| 6–17 s | "A number alone tells us nothing. To measure means to compare. We choose one length, and count how many times it fits." | A stick is laid end to end along the table: 1… 2. Caption: **Measure = compare** |
| 17–30 s | "That chosen length is called a unit. But which unit? With my hand span, the table is ten spans long. My friend has a bigger hand, and gets only eight. Same table, two different answers." | Small blocks count along the table: **10 spans**. Larger blocks: **8 spans**. Caption: **Same table, different answers** |
| 30–43 s | "So the whole world agrees on one standard for each unit. For length, it is the metre. A good standard never changes, and everyone can use it." | A bar labelled **1 metre**. Two ticks appear: **never changes**, **available to everyone** |
| 43–53 s | "Now the table is two metres. A number, and a unit. Anyone, anywhere, understands exactly the same length." | Two metre bars fit along the table. **2 m**, with labels **number** and **unit** |
| 53–60 s | "Measurement is a number times a unit. Next: why does physics need only seven base units?" | **Measurement = number × unit**, then **Next: the 7 base units** |

Narration is about 125 words, a slow, clear pace for 60 seconds.
